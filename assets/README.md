# assets

Shared brand and media assets used across the whole ecosystem — logos, fonts, brand videos, and images not specific to a single product. App-specific media (e.g. in-app food photography for Wolves Nutrition) lives with that app instead, under `wolves-nutrition/assets`.

| Folder | Purpose |
|---|---|
| `images/` | General-purpose images not covered by `logos/` or `brand/` |
| `logos/` | Logo files, all variants and formats |
| `videos/` | Brand and promotional video files |
| `fonts/` | Licensed font files used across products |
| `brand/` | Brand guidelines, color palettes, and style references |
