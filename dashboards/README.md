# dashboards

Interactive dashboards for viewing performance, nutrition, and program data. These are read-oriented surfaces for humans — they consume data produced by `wolves-nutrition`, `automation`, and other systems rather than owning business logic themselves.

| Folder | Purpose |
|---|---|
| `coach/` | Dashboard views for coaching staff (team/athlete performance overviews) |
| `athlete/` | Dashboard views for individual athletes (their own data only) |
| `admin/` | Administrative views (program-wide reporting, user management) |
| `shared/` | Shared components, charts, and data-fetching utilities used across all three dashboards |
