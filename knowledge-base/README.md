# knowledge-base

The reference library: external research and material that grounds decisions made elsewhere in the repo. This is curated reference material, not original analysis — active internal research and findings belong in `/performance-os/research` instead.

| Folder | Purpose |
|---|---|
| `research-papers/` | Peer-reviewed papers, general |
| `issn/` | International Society of Sports Nutrition position stands and resources |
| `gssi/` | Gatorade Sports Science Institute resources |
| `ncaa/` | NCAA rules, guidelines, and compliance documentation |
| `books/` | Book notes and references |
| `articles/` | Non-peer-reviewed articles and write-ups |
| `videos/` | Notes on and links to reference video content |
| `sports-science/` | General sports-science reference material not tied to a specific org above |
| `nutrition/` | Nutrition reference material not tied to a specific org above |
| `training/` | Training-methodology reference material not tied to a specific org above |

When a topic could fit multiple folders (e.g. a GSSI nutrition paper), file it under the most specific org-specific folder (`gssi/`) rather than the general topic folder (`nutrition/`).
