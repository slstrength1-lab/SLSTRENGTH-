# performance-os

The operating system for the human side of the program: how the performance staff plans, documents, and hands off work. This is where process lives — not application code.

| Folder | Purpose |
|---|---|
| `docs/` | Standing reference documentation (org structure, definitions, SOPs) |
| `agents/` | Operating notes for how each Claude agent (see `/claude-agents`) is used day-to-day |
| `handoffs/` | Structured handoff notes between staff, shifts, or agents |
| `prompts/` | Prompts specific to running performance-os itself (distinct from `/prompt-library`) |
| `research/` | Active internal research questions and findings, as opposed to the reference material in `/knowledge-base` |
| `meeting-notes/` | Dated notes from staff and coordination meetings |
| `roadmap/` | Where the program is headed, by quarter/phase |
| `systems/` | Descriptions of how each operational system works and connects to the others |
| `playbooks/` | Step-by-step procedures for recurring situations (onboarding an athlete, in-season load management, etc.) |
