# prompt-library

Reusable prompts, organized by category, for use by the agents in `/claude-agents` or directly by staff. Prompts specific to operating `performance-os` itself live in `/performance-os/prompts` instead.

| Folder | Purpose |
|---|---|
| `coaching/` | Prompts for programming, session planning, and athlete feedback |
| `nutrition/` | Prompts for meal planning and nutrition guidance |
| `research/` | Prompts for literature review and data analysis |
| `content/` | Prompts for social/marketing content generation |
| `coding/` | Prompts for software development tasks in this repo |
| `general/` | Prompts that don't fit a single category above |

Each prompt file should note which agent(s) it's designed for.
