# templates

Reusable templates so recurring documents, prompts, reports, and code don't get rebuilt from scratch each time.

| Folder | Purpose |
|---|---|
| `document-templates/` | Templates for docs — meeting notes, handoffs, playbooks |
| `prompt-templates/` | Skeletons for building new prompts (see `/prompt-library` for the prompts themselves) |
| `report-templates/` | Templates for recurring reports generated by `/automation/reporting` |
| `code-templates/` | Boilerplate/starter code for new modules (e.g. a new Claude agent, a new API route) |
